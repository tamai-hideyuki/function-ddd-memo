# 予約システム - DDDサンプルプロジェクト

## [作成進捗管理](./progress.md)

## 概要
ドメイン駆動設計の実践として、予約システムを題材に境界づけられたコンテキストとサブドメインの分類を行う

## ビジネス領域を分析する

### 想定するビジネス
美容院の予約管理システムを想定

### 主要な業務フローについて考えてみる
1. 顧客が希望日時とメニューを選んで予約を申し込む
2. スタッフが予約を確認し、スケジュールを調整する
3. 予約確定の通知を顧客に送る
4. 予約当日にサービスを提供する
5. サービス提供後、顧客情報と履歴を記録する

## 境界づけられたコンテキストについて

### 1. 予約管理コンテキスト（Reservation Context）
予約の作成、変更、キャンセルなどの中心的な業務ロジックを扱う

### 2. スケジュール管理コンテキスト（Schedule Context）
スタッフの勤務時間、空き時間の管理

### 3. 顧客管理コンテキスト（Customer Context）
顧客情報と予約履歴の管理

### 4. 通知コンテキスト（Notification Context）
予約確認・リマインダーの送信

### 5. 認証コンテキスト（Authentication Context）
ユーザーのログインと権限管理

## サブドメインの分類

### 中核サブドメイン（Core Domain）
**予約管理** - 競争優位性の源泉
- 予約の作成・変更・キャンセルのビジネスルール
- 二重予約の防止ロジック
- 予約可能時間の計算
- キャンセルポリシーの適用

### 一般サブドメイン（Generic Subdomain）
**認証・認可** - 業界標準的な機能
- ユーザー認証（ログイン/ログアウト）
- 権限管理（顧客/スタッフ/管理者）
- パスワード管理

**通知** - 一般的な通知機能
- メール送信
- SMS送信
- プッシュ通知

### 支援サブドメイン（Supporting Subdomain）
**スケジュール管理** - ビジネスを支援するが差別化要因ではない
- スタッフの勤務スケジュール登録
- 営業日カレンダーの管理
- 休憩時間の設定

**顧客管理** - 顧客情報の基本的な管理
- 顧客プロフィール管理
- 予約履歴の記録
- お気に入りメニューの保存

## ユビキタス言語を作ってみる

| 用語 | 定義 |
|------|------|
| 予約（Reservation） | 顧客が特定の日時にサービスを受けるための約束 |
| タイムスロット（TimeSlot） | 予約可能な時間枠（例：30分単位） |
| メニュー（Menu） | 提供されるサービスの内容と所要時間 |
| スタッフ（Staff） | サービスを提供する従業員 |
| 顧客（Customer） | サービスを受ける人 |
| 予約ステータス | 仮予約/確定/完了/キャンセル |
| キャンセルポリシー | 予約取消に関する規定（期限、料金等） |

## 作成したドメインモデルについて

 1. 予約管理コンテキスト [(reservation-context.md)](./contexts/reservation-context.md)
    - 中核サブドメインとして、予約の作成・変更・キャンセルの複雑なビジネスロジック
    - ReservationエンティティとTimeSlot値オブジェクトを中心とした設計
    - ダブルブッキング防止、キャンセルポリシーなどのドメインサービス
 2. スケジュール管理コンテキスト [(schedule-context.md)](./contexts/schedule-context.md)
    - スタッフの勤務スケジュール、営業日カレンダーの管理
    - 予約管理コンテキストとの共有カーネル（TimeSlot、StaffId）
    - シフトテンプレート、ローテーション機能
 3. 顧客管理コンテキスト [(customer-context.md)](./contexts/customer-context.md)
    - 顧客プロフィール、会員レベル、来店履歴の管理
    - 顧客セグメンテーション、重複顧客統合などのサービス
    - 生涯価値（LTV）計算機能
 4. 通知コンテキスト [(notification-context.md)](./contexts/notification-context.md)
    - マルチチャネル通知（メール、SMS、プッシュ）
    - 通知テンプレート、配信優先度、リトライ機能
    - 通知キャンペーン管理
 5. 認証コンテキスト [(authentication-context.md)](./contexts/authentication-context.md)
    - ユーザー認証・認可、セッション管理
    - 二要素認証、パスワードポリシー
    - ロールベースアクセス制御（RBAC）

###  各コンテキストは、エンティティ、値オブジェクト、ドメインサービス、リポジトリインターフェース、集約、ドメインイベントを含む完全なドメインモデルとして設計
